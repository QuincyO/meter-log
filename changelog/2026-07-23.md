Road and straight-line, both priced on real road distances so the shorter number really is

## AGENTS.md became the single instruction set for every agent

`7de260c`

`CLAUDE.md` had been the canonical copy with `AGENTS.md` as a fork of it. The fork silently
drifted several features out of date, so Codex was working from a description of an app that
no longer existed. `CLAUDE.md` now contains no instructions of its own — just a pointer. One
file, read by everyone, is the fix.

This is the reason durable knowledge goes in [AGENTS.md](../AGENTS.md),
[ARCHITECTURE.md](../ARCHITECTURE.md) or [VERIFY.md](../VERIFY.md) rather than any one
agent's private memory.

## Drive mode

`a25099c`, `0cdb353`, `ebc2047`

A single-card driving screen with silent GPS route recording. Recording is **opt-in per phone
per day** — the guard against a capture phone and a navigation phone both recording the same
drive — and uploads are deferred to end of day.

Recording runs app-wide rather than only on the Drive screen, but a web app gets **no GPS in
the background**. During a Maps hand-off the phone backgrounds the PWA and the leg pauses;
that's bracketed as an anchored gap and drawn dashed, rather than faked as a straight driven
line.

## Settings ▸ ⟳ Force update from GitHub

`4c56ee3`, `6008177`

The crew's escape hatch for a stale service worker. Three things in it are load-bearing: each
fetch bypasses the browser HTTP cache (GitHub Pages serves a `max-age`, so a plain refetch
re-stores the same stale bytes), nothing is deleted before a successful download (so a weak
boat signal can't strand a phone without an offline shell), and it touches Cache Storage
**only** — never localStorage or IndexedDB, or every installer would re-enter their details
and un-synced writes could vanish.
