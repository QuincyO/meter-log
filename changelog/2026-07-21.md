# 2026-07-21 — Real road distances, and a desktop planner

## Routing moved to Google Maps Platform

`9a47eba`, `96492df`, `96b0ce5`

Free-tier only, with a budget-guarded road matrix via the Routes API and navigation by
**address** rather than pin — the text the installer typed is the source of truth, and a
mis-geocoded pin must not steer the truck to the wrong spot. **OpenRouteService** was added as
a backup for both geocoding and the matrix.

A documentation correction the same day: the Geocoding web service rejects referrer-restricted
keys, which is not obvious from the console. `5c9b200`

## A desktop route planner

`a6a9e4d`, `1c96776`, `7ef68a8`

`planner.html`, backed by a **local OSRM** matrix source — no per-call cost, no quota. Later
joined by optional local Nominatim geocoding and scripts to clone both onto another PC's SSD.

## Geo-restricted geocoding, home-anchored routing, order repair

`2f5f29d`, `bdf94da`, `8168ed8`

Geocoding restricted to the working region so a street name doesn't resolve to another
province; routes anchored toward the installer's home; colliding worklist `order` values
repaired; worklist pins kept when a geocode fails rather than dropped; parked / pick-town
state and the full address shown on the cards.

## Land mode

`0bbe08e`, `21cdfd3`, `667729e`, `5739d74`

End-of-day refinements, a no-GPS logging override for when a fix won't come, downtime allowed
on the first work order, a widened land-PDF header, and a Visited count in the totals row.

## Smaller things

- A quiet plan-mode "expected stops today" estimate on the capture page. `39ff533`
- iOS opens Google Maps directly, falling back to Apple Maps — iOS has no OS setting to pick
  a default maps app, unlike Android. `7d70547`
- WO# copied to the clipboard after logging in plan mode. `8010906`
- Capture form reordered: address first, conflict chooser last. `2fd4599`
- New J# cleared on switch to UTI, and the UTI reason became a dropdown, on both the capture
  card and the edit page. `6fab81f`, `2b957b4`
