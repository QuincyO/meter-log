# 2026-07-18 — Land mode, and archive-before-delete

## Land-work mode

`06b4110`

A persisted Boat/Land toggle (blue/green accents) switching the capture page and teams admin
between the two, a **full-page worklist** with plan mode replacing the old popup sheet, and a
land-specific daily-log PDF template — header strip, per-WO delay columns, totals row, no
travel column.

Plan mode feeds the capture form: the first pending order fills in, and each logged stop
advances to the next.

## Removing a stop became a move, not a delete

`b0afc3c`

Stops are archived to a `StopsArchive` tab with who removed them and why. The copy is
appended **before** the source is deleted, so a crash duplicates rather than loses. An
archive call for an id that's already gone returns a terminal success on purpose — that's
what stops a phone's offline queue wedging forever on a stop the office removed.
