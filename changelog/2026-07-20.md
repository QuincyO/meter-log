# 2026-07-20 — Route optimization arrives; a long bug-fixing day

## Land-mode worklist route optimization

`3ededbe`, `82fde93`, `3392bc4` — the first version, with Or-opt improvement and colliding
`order` values fixed.

## Worklist sync across devices

`774bdaf`, `546c0be`, `f995f3e`

Manual ⇪ Upload / ⇩ Download against the `Worklist` tab, **keyed on H number rather than
installer name** — same-name installers were colliding. Plus a per-order Directions button,
auto-sync, a nightly done-order cleanup, and day totals.

## A user guide and an in-app Help page

`b51615a` — `USER-GUIDE.md` plus an offline Help page, so the crew has an answer without
signal.

## GPS capture became manual, then mandatory

`b9f762a`, `28b25cf` — address and GPS fetch on Refresh only (the automatic fetch was firing
constantly), but coordinates are now **required** on every stop log.

## Background jobs surfaced in the top status pill

`a58d98a` — no more silent work.

## Worklist drag reorder, fixed twice

`db40f38`, `c886aa9`

First queue position numbers, then binding release to `window` rather than the handle. The
reorder releases pointer capture, after which up/move no longer reliably reach the handle —
the "card stuck highlighted on lift" bug. Events always bubble to `window`, so release is
never missed.

## Offline robustness

`fde44d0`, `0b35257`, `0f792ed`, `6d714f3`

Stop wedging sync on a lying `navigator.onLine`; actually queue the End-of-Day close when the
live close fails; surface the real `loadDay` error instead of a generic "Offline", with the
detail in the console and a plain message on screen.

## Smaller things

- Reuse the top Old J# for unreadable-meter installs. `3d0923e`
- Fixed an edit-page crash on a numeric unit value. `4b6f4f4`
